# Quick Setup: Built-In LLM Provider for Development

**Problem:** Papillion's BuiltIn LLM provider requires bundled GGUF model files.

**Solution:** Follow these steps to test locally.

## Step 1: Get the Model Files

Download a small quantized model. Recommended: **TinyLLaMA 1.1B** (2.2GB)

```bash
# Create the models directory
mkdir -p apps/papillion/models

# Download TinyLLaMA weights (~2.2GB)
cd apps/papillion/models
curl -L -O https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf

# Download tokenizer (shared across all models)
curl -L -O https://huggingface.co/TinyLlama/TinyLlama-1.1B-Chat-v1.0/resolve/main/tokenizer.json

cd ../../
```

## Step 2: Verify File Placement

```bash
ls -lh apps/papillion/models/
```

Expected output:
```
-rw-r--r--  1 user  staff  2.2G Jan 1 12:00 tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf
-rw-r--r--  1 user  staff  500K Jan 1 12:00 tokenizer.json
```

## Step 3: Update Model Catalog

Edit `crates/papillion-shared/src/types.rs` to match your downloaded filename:

```rust
pub fn builtin_model_catalog() -> Vec<BuiltInModelInfo> {
    vec![
        BuiltInModelInfo {
            id: "tinyllama-1.1b".into(),
            display_name: "TinyLLaMA 1.1B".into(),
            repo: "TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF".into(),
            filename: "tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf".into(),  // ← Match your file
            size_hint: "2.2 GB".into(),
        },
    ]
}
```

## Step 4: Run Development Server

```bash
cd apps/papillion
cargo tauri dev
```

## Step 5: Configure LLM Provider

In the app:
1. Click **⚙️ Settings** (top-right)
2. Click **"General"** tab
3. Select **LLM Provider: Built-in (Recommended)**
4. Select model: **TinyLLaMA 1.1B**
5. Click **Save**

Watch the console output. You should see:
```
Orchestrator status: Ready (no errors)
```

If you see "Could not save settings — backend unavailable", check the terminal for:
```
Bundled model not found: tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf (expected at ...)
```

## Debugging

### Model File Not Found

```bash
# Check file exists
file apps/papillion/models/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf

# Check Tauri is looking in the right place
# Run: cargo tauri dev
# In terminal, you'll see the full path it's looking for
```

### Tokenizer Missing

```bash
# Tokenizer must be named exactly "tokenizer.json"
ls apps/papillion/models/tokenizer.json
```

### Model Load Takes Forever

TinyLLaMA first-load can take 30-60 seconds (loading 2GB into RAM). Be patient.

### Model Load Fails

Check tokenizer.json is valid JSON:
```bash
python3 -m json.tool apps/papillion/models/tokenizer.json > /dev/null && echo "Valid JSON"
```

## Verify It Works

Once status shows "Ready":

1. Go to **"Browse Registries"** (in TopBar menu)
2. Create a new canvas
3. Type a prompt in the canvas (e.g., "What is 2+2?")
4. You should see responses generated by the on-device model

## Storage

Models are LARGE. **Do NOT commit to git.**

Check `.gitignore` — should already have:
```
apps/papillion/models/*.gguf
```

(Keep `tokenizer.json` in git, it's only 500KB.)

## For Production

When building with `cargo tauri build`, ensure models are in the correct platform location before building. See `docs/MODEL_DIRECTORY_QUIRK.md` for details.
